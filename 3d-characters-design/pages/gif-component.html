3D击鼓人组件

可直接嵌入网页的动画组件

360度旋转循环 / 白底透明 / 3D京剧击鼓人

使用示例

三种嵌入方式，覆盖从简单到响应式的常见场景

基础嵌入

复制代码 
<div class="opera-drummer">
  <img src="opera-drummer-3d.gif"
       alt="3D击鼓人"
       width="200">
</div>

带容器样式

复制代码 
<div class="opera-drummer-container">
  <img src="opera-drummer-3d.gif"
       alt="3D击鼓人"
       class="opera-drummer-gif">
  <p>英歌舞击鼓人</p>
</div>

响应式适配

复制代码 
<div class="opera-drummer-responsive">
  <img src="opera-drummer-3d.gif"
       alt="3D击鼓人"
       loading="lazy">
</div>

组件 CSS

复制以下 CSS 到你的项目中，即可使用上述全部样式类

复制代码 
/* 3D击鼓人 GIF 组件样式 */

/* 基础居中类 */
.opera-drummer {
  display: inline-block;
  text-align: center;
}

.opera-drummer img {
  display: block;
}

/* 带容器样式 - 卡片式展示 */
.opera-drummer-container {
  display: inline-flex;
  flex-direction: column;
  align-items: center;
  padding: 24px;
  border-radius: 16px;
  background: rgba(26, 26, 34, 0.9);
  border: 1px solid rgba(212, 168, 67, 0.15);
  text-align: center;
}

.opera-drummer-container p {
  margin-top: 12px;
  font-size: 14px;
  color: #9A9AAE;
}

/* GIF 图片样式 + 悬停效果 */
.opera-drummer-gif {
  max-width: 100%;
  height: auto;
  transition: transform 0.3s ease, filter 0.3s ease;
}

.opera-drummer-gif:hover {
  transform: scale(1.08);
  filter: drop-shadow(0 0 18px rgba(196, 30, 36, 0.5))
         drop-shadow(0 0 6px rgba(212, 168, 67, 0.4));
}

/* 响应式容器 */
.opera-drummer-responsive {
  width: 100%;
  max-width: 300px;
  margin: 0 auto;
}

.opera-drummer-responsive img {
  width: 100%;
  height: auto;
  display: block;
}
