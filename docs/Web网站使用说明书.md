# 云焕非遗 —— Web网站使用说明书

## 一、系统简介

「云焕非遗」是一个英歌文化数字展示平台，面向普通用户提供英歌舞文化浏览、互动体验、AI问答等功能，面向管理员提供全套内容管理后台。本说明书将分步骤指导用户完成各功能模块的操作。

## 二、运行环境与访问方式

### 2.1 运行环境要求

- **浏览器**：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+（需支持 WebGL 2.0）
- **网络**：需可访问本地服务器（局域网或本机）
- **分辨率**：建议 1920×1080 及以上，支持响应式适配移动端

### 2.2 访问方式

1. 确认前端与后端服务器均已启动
2. 打开浏览器，在地址栏输入：`http://127.0.0.1:3000/`
3. 按回车键，等待页面加载完成

> **截图参考**：`首页_导航栏_默认状态.png`、`首页_Hero区域_首屏.png`

### 2.3 页面加载说明

- 首次访问时页面会显示加载动画（旋转圆环 + "加载中..."文字），待数据从后端加载完成后自动显示内容
- 若长时间停留于加载界面，请检查后端服务器（端口4000）与数据库（端口3306）是否正常运行

## 三、登录与账号权限说明

### 3.1 普通用户

- **无需登录**即可浏览所有前台展示页面
- 可使用搜索、AI问答、脸谱DIY等全部互动功能
- 点击通知公告可跳转至微信公众号查看原文

### 3.2 管理员用户

**登录入口**：在浏览器地址栏输入 `http://127.0.0.1:3000/admin/login`

**登录步骤**：

1. 打开管理员登录页面，页面中央显示"管理员登录"表单
2. 在"用户名"输入框中输入管理员用户名（默认：`admin`）
3. 在"密码"输入框中输入管理员密码（默认：`admin123`）
4. 点击"登录"按钮
5. 登录成功后自动跳转至管理后台仪表盘页面（`/admin/dashboard`）
6. 若登录失败，表单上方将显示红色错误提示

**权限说明**：
- 管理员登录后可访问全部后台管理模块
- 管理员可在后台对各模块内容进行新增、编辑、删除操作
- 点击侧边栏底部的"退出登录"按钮可退出管理后台

该页面提供基于大语言模型的智能问答服务。

**功能区域**：
- 顶部Banner图与页面标题

- 底部输入框与发送按钮

**操作步骤**：
1. 进入AI导游页面
2. 在底部输入框中输入问题（如"英歌舞的起源是什么？"）
3. 点击发送按钮或按 Enter 键 → AI开始生成回答
4. 等待AI回答加载完成，回答以Markdown格式渲染
5. 可继续输入追问问题进行多轮对话
6. 点击"清除对话"按钮可重置聊天记录
7. **拖拽功能**：按住对话框顶部拖拽 → 可将对话框移动至页面任意位置；拖拽超过阈值后进入浮动模式
8. **展开/收起**：点击展开按钮可切换对话框尺寸
9. **模型切换**：点击顶部下拉菜单可切换不同的AI模型

## 六、常见问题与故障排查

### 6.1 页面无法访问

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 页面显示"Cannot GET /" | 前端服务器未启动 | 在项目根目录执行 `npm run dev` |
| 页面持续显示"加载中..." | 后端服务器或数据库未启动 | 启动后端服务器（`server/` 目录执行 `npm start`）并检查 MySQL 服务 |
| 图片无法显示 | 后端静态文件服务未启动或路径错误 | 确认后端服务器运行在4000端口，检查 `/static` 路径代理配置 |
| 页面样式错乱 | 浏览器缓存 | 清除浏览器缓存后刷新页面（Ctrl+F5） |

### 6.2 AI导游无响应

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 发送消息后无回复 | AI模型API连接失败 | 检查网络连接与API密钥配置 |
| 回复内容异常 | 模型服务异常 | 尝试切换其他模型 |

### 6.3 管理员登录失败

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 提示"登录失败" | 用户名或密码错误 | 确认使用正确的管理员账号密码 |
| 登录后跳转回登录页 | Token过期或无效 | 清除浏览器 localStorage 后重新登录 |

### 6.4 视频无法播放

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 视频区域空白 | 视频资源未配置 | 管理员在后台首页管理中配置视频地址 |
| 播放卡顿 | 网络带宽不足 | 等待缓冲或切换网络环境 |

## 七、操作注意事项

1. **浏览器兼容性**：本平台使用了WebGL、CSS动画等现代Web技术，请使用最新版Chrome、Firefox或Edge浏览器以获得最佳体验。
2. **3D内容加载**：文创周边的3D吉祥物与脸谱DIY的3D预览功能需要WebGL支持，部分低端设备可能加载较慢。
3. **AI问答**：AI导游的回答由大语言模型生成，仅供参考，重要信息请以平台展示的文化资料为准。
4. **外部链接跳转**：点击通知公告和实践足迹卡片会跳转至微信公众号外部链接，系统会弹出确认对话框提示。
5. **管理员操作**：在后台管理系统中执行删除操作前请仔细确认，删除后数据不可恢复。
6. **数据时效性**：通知公告、演出时间表等信息由管理员维护，如发现信息过期请联系管理员更新。
7. **移动端适配**：平台已做响应式适配，在手机和平板上可正常浏览，但3D交互功能建议在桌面端使用。
8. **搜索功能**：导航栏搜索支持页面名称、板块名称、关键词、描述的多维度匹配，支持键盘快捷操作（↑↓切换、Enter跳转、ESC关闭）。
