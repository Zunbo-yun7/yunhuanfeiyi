# 云焕非遗 —— 英歌文化数字展示平台

## 一、项目概述

「云焕非遗」是一个面向国家级非物质文化遗产——英歌舞的综合性数字展示与管理平台。项目以广东省普宁地区新坛英歌队为核心案例，通过现代化的Web技术手段，系统性地呈现英歌舞的历史渊源、流派分支、动作图谱、脸谱装备、队伍风采、演出排期及传承人故事等内容，并集成AI智能问答、脸谱DIY互动创作、AR文创体验等创新功能，致力于推动传统文化的数字化传承与传播。

平台名称"云焕非遗"寓意以云计算与数字技术焕发非遗文化新活力，让古老的英歌艺术在数字时代焕发新的光彩。

## 二、建设背景

英歌舞起源于明代，距今已有约400年历史，是潮汕地区最具代表性的民间舞蹈之一，于2006年被列入第一批国家级非物质文化遗产名录。然而，随着现代化进程加速，英歌舞面临着传承人老龄化、青年参与度下降、传播渠道有限等困境。

本项目由高校"三下乡"社会实践团队发起，在深入普宁地区实地调研的基础上，结合数字媒体技术与Web开发技术，构建了一个集文化展示、互动体验、内容管理于一体的综合性数字平台，旨在：

- 系统记录和展示英歌舞文化全貌
- 通过互动体验吸引年轻群体关注非遗
- 为英歌队提供演出排期与队伍管理工具
- 建立可持续的内容更新与管理机制

## 三、目标用户

| 用户类型 | 使用场景 | 权限说明 |
|---------|---------|---------|
| 普通访客 | 浏览英歌文化内容、观看展演视频、DIY脸谱、AI问答 | 无需登录，可访问所有展示页面 |
| 文化研究者 | 查阅英歌历史资料、流派信息、传承人故事 | 同普通访客 |
| 英歌队成员 | 查看演出排期、了解队伍动态 | 同普通访客 |
| 学生群体 | 通过互动功能学习英歌文化、体验脸谱DIY | 同普通访客 |
| 管理员 | 管理平台所有内容、发布通知公告、维护演出排期 | 需账号登录，拥有后台管理权限 |

## 四、核心业务价值

1. **文化数字化保存**：将英歌舞的历史、动作、脸谱、装备等知识体系进行结构化数字化记录，形成可持久保存的文化数据库。
2. **沉浸式互动体验**：通过3D吉祥物展示、AR增强现实体验、在线脸谱DIY等功能，将传统文化以现代互动方式呈现，提升用户参与感。
3. **AI智能导览**：集成大语言模型（DeepSeek），提供7×24小时智能问答服务，随时解答用户关于英歌文化的疑问。
4. **演出信息管理**：为英歌队提供演出排期日历、节目单管理、演员阵容维护等实用工具，提升队伍运营效率。
5. **内容持续运营**：后台管理系统支持管理员随时更新各模块内容、发布公众号文章通知，确保平台内容时效性。

## 五、整体功能架构

平台采用前后端分离架构，分为**前台展示系统**与**后台管理系统**两大模块：

```
云焕非遗平台
├── 前台展示系统（用户端）
│   ├── 首页（综合概览）
│   ├── 认识英歌（历史文化）
│   ├── 新坛英歌（队伍介绍）
│   ├── 动作图谱（招式阵法）
│   ├── 脸谱装备（色彩道具）
│   ├── 文创周边（吉祥物/AR/产品）
│   ├── 脸谱DIY（互动创作）
│   ├── 演出时间表（排期日历）
│   ├── 人物故事（传承人）
│   ├── 实践日志（三下乡记录）
│   ├── AI导游（智能问答）
│   └── 通知公告（全屏列表）
│
└── 后台管理系统（管理端）
    ├── 仪表盘（数据概览）
    ├── 首页管理
    ├── 新闻稿管理
    ├── 公众号文章管理
    ├── 认识英歌管理
    ├── 新坛英歌管理
    ├── 动作图谱管理
    ├── 脸谱装备管理
    ├── 人物故事管理
    ├── 演出时间表管理
    ├── 实践日志管理
    └── 文创商品管理
```

## 七、部署环境

| 层级 | 技术选型 |

- Node.js >= 18
- MySQL >= 8.0

## 八、适用场景

1. **文化遗产数字化展示**：适用于各级非遗保护机构、文化馆、博物馆构建数字化展示平台。
2. **高校社会实践成果展示**：适用于高校"三下乡"等社会实践团队展示调研成果与文化记录。
3. **民间艺术团队宣传门户**：适用于各类民间艺术团队建立官方网站，展示队伍风采与演出信息。
4. **文化教育互动课堂**：适用于中小学或高校文化课程中，学生通过互动方式学习传统文化。
5. **地方文旅推广平台**：适用于地方文旅部门推广特色非遗文化资源。
